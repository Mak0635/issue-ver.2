# トップをお店仕様にする

## 概要
トップ（サイトを開いて最初に見える部分）が仮の文字のままなので、オリジナルのカフェにしたい。

## やること
- [ ] `<h1>` の「お店の名前が入ります」を、考えたカフェの名前に変える
- [ ] 「ここにキャッチコピーが入ります」を、お店のキャッチコピーに変える（例: 「朝の一杯を、もっと特別に。」）
- [ ] 背景色 `bg-gray-300` を、お店の雰囲気に合う色に変える（例: `bg-amber-100`）
- [ ] ボタンの色 `bg-gray-500` を好きな色に変える（例: `bg-amber-700`）
- [ ] （余裕があれば）ボタンにマウスを乗せたときに色が変わるようにする（例: `hover:bg-amber-800`）

## 変更する場所
`index.html` の **【Issue #1 担当】** と書かれたコメントの間だけ

## 完了条件
- ブラウザで開くと、お店の名前・キャッチコピー・新しい色が表示されている
- 【Issue #1 担当】の範囲の外は変更していない

## ヒント
- Tailwind の色一覧: https://tailwindcss.com/docs/background-color
- 色の名前（amber, orange, stone…）と濃さ（100〜900）を組み合わせて使います
