# メニューを3品にする

## 概要
メニューセクションにカードが1枚しかない。3品分のメニューを並べたい。

## やること
- [ ] 「▼ メニューカード 1品分（ここから）」〜「▲（ここまで）」をコピーして、合計3枚にする
- [ ] それぞれのカードの「商品名」「商品の説明」「¥000」を書き換える
- [ ] 絵文字 ☕ を商品に合う絵文字に変える（例: 🍰 🥪 🧋 🍵）
- [ ] （余裕があれば）おすすめの1品だけ、カードの枠線や背景色を変えて目立たせる（例: `border-2 border-amber-500`）

## 変更する場所
`index.html` の **【Issue #2 担当】** と書かれたコメントの間だけ

## 完了条件
- PC 幅のブラウザでカードが横に3枚並んでいる
- スマホ幅（ブラウザの幅を狭くする）では縦に並んでいる
- 【Issue #2 担当】の範囲の外は変更していない

## ヒント
- `<div class="bg-white ...">` から、それに対応する `</div>` までが1枚のカードです
- 開始タグと終了タグの数がずれると表示が崩れます。インデント（字下げ）を揃えると見つけやすいです
