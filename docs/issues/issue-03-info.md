# 店舗情報（営業時間・住所）を追加する

## 概要
店舗情報にコピーライトしかないので、お客さんが知りたい営業時間や住所を追加したい。

## やること
- [ ] 営業時間と定休日を追加する（例: `営業時間 8:00〜18:00 ／ 定休日 水曜日`）
- [ ] 住所と電話番号を追加する（架空のものでOK。例: `東京都〇〇区1-2-3` / `03-0000-0000`）
- [ ] 電話番号はタップすると電話がかけられるリンクにする（ヒント参照）
- [ ] `&copy; 20XX お店の名前` を正しい年とお店の名前に変える
- [ ] （余裕があれば）営業時間と住所を横並びにする（例: `<div class="flex justify-center gap-8">`）

## 変更する場所
`index.html` の **【Issue #3 担当】** と書かれたコメントの間だけ

## 完了条件
- 店舗情報に営業時間・定休日・住所・電話番号・正しいコピーライトが表示されている
- 【Issue #3 担当】の範囲の外は変更していない

## ヒント
- 電話リンク: `<a href="tel:0300000000">03-0000-0000</a>`
- 余白を空けたい時は `mb-4`（下に余白）などを使います
- 文字を太くしたい時は `font-bold` を使います
